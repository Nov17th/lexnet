# eval/

`baseline-2026-10-06/` is the data as it was handed to the reviewers on 6 October 2026: concepts and words chosen, and levels, pinyin, IPA, Wikidata items and lexemes filled in automatically from the sources listed in the main README. Only the reviewers' working notes were removed.

Do not edit it. `scripts/report_stats.py` compares `data/` with this baseline to count how many automatic values the reviewers kept, changed, removed or added; these numbers are used in the evaluation section of the report.
