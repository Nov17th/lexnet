# Report

`LexNet-report.pdf` is the project report, written on Overleaf with the course template and compiled with XeLaTeX.

- `stats.tex`: every number quoted in the report, as LaTeX macros (`\lxConcepts`, `\lxTriples`, ...), generated by `scripts/report_stats.py`. Do not edit.
- `figures/`: the report's figures. `model.tex` (Figure 1) and `pipeline.tex` (Figure 3) are TikZ sources and need the TikZ libraries `positioning` and `arrows.meta`; `model.tex` also loads `shapes.geometric` itself, for its ellipses. `web-bank.png` (Figure 5) is a screenshot of the web application.
